# The Eras of Baseball Maze
### By Ben Taylor

Welcome to my baseball maze! 

This maze will take you through the different eras of baseball history. Follow the clues in each folder to find your way to the solution.

## Clues
1. Navigate to the maze folder in your terminal using 'cd'
2. Use 'ls' whenever you want to see what is in your folder
3. Use 'cd' whenever moving into a new folder
4. Not everything is visible initially, if you feel like something is missing use 'ls -a'
5. Keep going until you find the solution

Good luck and enjoy completing the maze!
