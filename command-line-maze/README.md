# The Eras of Baseball Maze
### By Ben Taylor

Welcome to my baseball maze! This maze will take you through the different eras of baseball history. Follow the clues in each folder to find your way to the solution.

## Clues
Navigate to the maze folder in your terminal using 'cd'
Use 'ls' whenever you want to see what is in your folder
Use 'cd' whenever moving into a new folder
Not everything is visible initially, if you feel like something is missing use 'ls -a'
Keep going until you find the solution

Good luck and enjoy completing the maze!
